# 时间块议程计时器用户手册

## 一、简介
时间块议程计时器是一款轻量级工具，旨在帮助用户高效管理任务时间、记录会议笔记。通过创建多个时间块，您可以清晰规划日程并严格执行，提升时间利用效率。

## 二、界面说明
### 2.1 主要区域
- **计时器显示区**：页面顶部大字体区域，显示当前剩余时间
- **时间块列表区**：展示已添加的所有任务时间块
- **控制按钮区**：包含计时器启停、暂停/继续等控制按钮
- **导入导出区**：提供CSV格式的时间块导入导出功能
- **会议笔记区**：计时器运行时可在此记录相关笔记
- **时间调整区**：暂停时可调整当前任务时间或从未来任务借时间

### 2.2 界面元素
| 元素名称 | 功能描述 |
|---------|---------|
| `timerDisplay` | 显示当前剩余时间，警告时会变为橙色并闪烁 |
| `timeBlocksList` | 展示所有时间块，当前运行的时间块会高亮显示 |
| `startStopBtn` | 启动/停止计时器 |
| `pauseResumeBtn` | 暂停/继续计时器 |
| `modifyBtn` | 打开时间调整界面 |
| `noteSection` | 会议笔记输入和保存区域 |
