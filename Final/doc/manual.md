# 时间块议程计时器用户手册

## 一、简介
时间块议程计时器是一款轻量级工具，旨在帮助用户高效管理任务时间、记录会议笔记。通过创建多个时间块，您可以清晰规划日程并严格执行，提升时间利用效率。

## 二、界面说明
### 2.1 主要区域
- **计时器显示区**：页面顶部大字体区域，显示当前剩余时间
- **时间块列表区**：展示已添加的所有任务时间块
- **控制按钮区**：包含计时器启停、暂停/继续等控制按钮
- **导入导出区**：提供CSV格式的时间块导入导出功能
- **会议笔记区**：计时器运行时可在此记录相关笔记
- **时间调整区**：暂停时可调整当前任务时间或从未来任务借时间

### 2.2 界面元素
| 元素名称 | 功能描述 |
|---------|---------|
| `timerDisplay` | 显示当前剩余时间，警告时会变为橙色并闪烁 |
| `timeBlocksList` | 展示所有时间块，当前运行的时间块会高亮显示 |
| `startStopBtn` | 启动/停止计时器 |
| `pauseResumeBtn` | 暂停/继续计时器 |
| `modifyBtn` | 打开时间调整界面 |
| `noteSection` | 会议笔记输入和保存区域 |
## 三、基本操作

### 3.1 添加时间块
1. 在"Add Time Block"区域：
   - 在文本框输入任务名称（例如：项目介绍）
   - 在数字框输入所需分钟数（默认10分钟，最小值为1）
2. 点击`+ Add`按钮完成添加
3. 添加成功后：
   - 任务名称输入框自动清空
   - 分钟数输入框重置为10分钟

### 3.2 管理时间块
- **查看**：所有添加的时间块会按顺序显示在"Your Time Blocks"区域，包含序号、名称、时长和删除按钮
- **删除**：点击时间块右侧的`X`按钮删除（计时器运行时不可删除）

### 3.3 计时器控制
- **启动**：点击`Start timer`按钮，从第一个时间块开始计时
- **暂停**：运行时点击`Pause`按钮暂停计时，按钮变为`Resume`
- **继续**：暂停时点击`Resume`按钮继续计时，按钮变回`Pause`
- **停止**：点击`Stop Timer`按钮，计时器停止并重置所有状态
## 四、特色功能

### 4.1 会议笔记整合
1. 计时器启动后，"Meeting Notes"区域自动显示
2. 在文本框中输入与当前任务相关的笔记
3. 点击`Save Note`按钮保存，笔记会记录：
   - 对应任务名称
   - 记录时的剩余时间
   - 本地时间戳
4. 保存成功后输入框会清空，并显示提示信息

### 4.2 时间块警告系统
- 当当前时间块剩余时间≤1分钟时：
  - 计时器显示变为橙色
  - 文字会以1秒为间隔闪烁（透明度变化）
- 每个时间块的警告仅触发一次

### 4.3 动态时间调整
1. 暂停计时器后，点击`Modify Time`按钮打开调整界面
2. 两种调整方式：
   - **快速添加**：点击`+ 5 Min`或`+ 10 Min`为当前任务增加时间
   - **从未来任务借时间**：
     1. 界面会列出所有未开始的任务
     2. 点击目标任务的`Borrow`按钮
     3. 输入要借的分钟数（不可超过该任务总时长）
     4. 确认后时间会从未来任务转移到当前任务
3. 完成调整后点击`Close / Resume`关闭界面并继续计时

## 五、导入导出功能

### 5.1 导出时间块
1. 点击`Export CSV`按钮
2. 系统会生成名为`timeblocks_agenda.csv`的文件
3. 文件包含字段：任务名称（TaskName）、时长（分钟）（Duration(Minutes)）

### 5.2 导入时间块
1. 点击`Import CSV`按钮，选择符合格式的CSV文件
2. 注意：计时器运行时无法导入，需先停止
3. 导入成功后会显示导入的时间块数量

## 六、初始设置
页面加载完成后，会自动添加3个示例时间块：
- Project Overview（5分钟）
- Feature Discussion（10分钟）
- Action Items（5分钟）
